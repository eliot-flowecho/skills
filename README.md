# Eliot's Agent Engineering(EAE) Skills

A set of skills that designed to fix the gaps of agentic development.

## Install

```bash
npx skills add eliot-flowecho/skills
```

## Skills Included

### `/explore`

Have an idea but not sure if it's worth to try it? Use `/explore`, agent will
ask you one question at a time and do research and make experiements, demos to
let you see the effect, so you know.

### `/implement-early`

Know what you want to build, but expect implementation to teach you things?
Use `/implement-early`, agent will implement the work without constantly
redesigning it, but stop when reality conflicts with decisions you already made.

### `/next-slice`

Know the direction, but not what to build next? Use `/next-slice`, agent will
choose one vertical slice you can actually run or use, without planning the
rest of the project or turning it into a backlog.

### `/revisit`

Been building and using the project for a while? Use `/revisit`, agent will
look back at real implementations, workarounds, bugs, and feedback to find
earlier decisions that are now worth reconsidering, without redesigning the
system for you.
